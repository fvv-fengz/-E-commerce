# 拼多多数据提取_1 — 运行流程
## 常用命令

```bash
python scripts/run_template_trial.py --template doc/scrape-template-pdd-拼多多数据提取_1-smoke.json
python scripts/run_template_trial.py --template doc/scrape-template-pdd-拼多多数据提取_1.json
```

**不改模板、只跑全店铺模块 D（售后单下载）**：用 `--page-ids` 过滤；每家店仍需先登录，因此须同时包含登录页与售后页（顺序由模板 `pageIds` 决定，这里集合内两项即可）：

```bash
python scripts/run_template_trial.py --template doc/scrape-template-pdd-拼多多数据提取_1.json --page-ids pdd_login_switch,pdd_aftersale_export
```

**不改模板、全店铺只测模块 D + E（售后单 + 对账）**：同样用 `--page-ids`，须包含登录页、模块 D、模块 E（执行顺序为模板 `pageIds` 中的先后，过滤后实际为：登录 → 售后 → 对账，跳过 B/C）：

```bash
python scripts/run_template_trial.py --template doc/scrape-template-pdd-拼多多数据提取_1.json --page-ids pdd_login_switch,pdd_aftersale_export,pdd_cashier_bills_reconcile
```

可选：`--global-accounts 店A,店B` 覆盖 CSV 中的店铺列表；`--checkpoint` / `--resume` 与过滤后的页组合使用。

汇总采集 Excel 默认路径：`output/拼多多数值提取_{运行当天YYYYMMDD}.xlsx`（由模板根字段 `aggregateExcelFileStem` 控制；仍可用 `--excel-out` 覆盖）。


## 模块A：登录切号
1. 跳转 `https://mms.pinduoduo.com/login/`
2. 点击「账号登录」标签
3. 从 `doc/pdd_店铺账号信息.csv` 按当前店铺名读取主账号，填入 `#usernameId`
4. 点击登录按钮

z

## 模块C：推广概览模块
1. 跳转 `https://yingxiao.pinduoduo.com/goods/report/promotion/overView?beginDate={{yday}}&endDate={{yday}}&msfrom=mms_sidenav`
2. `beginDate/endDate` 固定为昨天（运行时自动替换 `{{yday}}`）。
3. 先点击「表格」视图，再取消「对比时间」勾选（若不存在则跳过，不中断）。
4. 在表格中定位“总和”行，按列头读取：
   - 成本花费(元)
   - 净实际投产比
   - 每笔净成交花费(元)
5. 三项均只取文本中的第一个数字（如“13.10 8.22%”仅取 `13.10`），写入汇总表并带店铺字段。

## 模块D：售后单导出
1. 进入 `https://mms.pinduoduo.com/print/after-sale-list`
2. 可选关闭广告弹窗（`continueOnFail`）。
3. **时间类型**下拉切为「售后申请时间」（左侧标签为「时间类型」；不点 Portal「确认」，与当前页行为一致）。
4. **不选日期范围**，沿用页面默认时间区间。
5. 点击「查询」→「下载数据」展开菜单 →「下载查询订单」触发导出。
6. 下载文件命名模板：`{account}_售后单_raw_{yday}{ext}`（`{yday}` 为运行日「昨天」占位，与页面筛选无关时可再改模板）。
7. 每次运行在 `downloads` 下自动新建子目录：`{任务名}_{运行日期}`。

## 模块E：对账中心

1. **多店 `globalAccountLoop` 时，对账页与前几页共用同一标签**（模板**未**启用 `openInNewTab`）：避免「对账在新标签、主标签已开始下一家登录」的双标签时序干扰。地址：`https://mms.pinduoduo.com/cashier/finance/payment-bills`。若站点重定向到 `cashier.pinduoduo.com`，以实际为准。
2. **时间范围**：先点击时间筛选容器打开浮层，再点快捷「昨天」。
   - 容器：`//*[@id="root"]/div/div[2]/div/div[1]/div/div[3]/div/div[2]/div[2]/div/div[1]/div/div/div[1]/div/div/div/div/div/div[1]/input`
   - Portal 内按钮（文案「昨天」，class 随版本变化，勿写死 hash）：`body > div[class*='PT_dropdown'][class*='PP_dropdown'] ... div[class*='RPR_quickPickerWrapper'] button span`（以实际 DevTools 为准）。
3. **展开高级选项**（进入收银台账单页后）：点击 `#root > div > div.Container_container__6H_RU > ... > div.btn-group > div > a`，或点文案「展开高级选项」，露出「账务类型」等筛选项。
4. **账务类型（与当前图示一致）**  
   - **勾选**：技术服务费、多多进宝、扣款、其他、其他服务、分账、服务消费（共 7 项）。  
   - **不勾选**：交易收入、优惠券结算、提现、转账、退款（共 5 项）。  
   自动化可用 `getByRole('checkbox', { name: '…' })` / `label:has-text('…')` 逐项对齐；发版后若默认勾选变化，以页面为准更新本列表。
5. 先点击「查询」，再点击「导出」（如 `#exportBalance-btn`；长 class 会随发版变化，以模板 `pdd_cashier_query` / 导出相关步为准）。
6. **导出提交后页面会自动跳转**（常见进入「账单申请」列表或跳转至 `cashier.pinduoduo.com` 导出记录等）。待新页/列表渲染完成后，在对应行点击 **「下载账单」**（如 `[id^='downloadBalance-btn']` / `下载账单` 文案），即可触发浏览器下载；试运行脚本对该步使用 `expect_download` 并写入 `output/downloads/…`。
7. 下载文件本地重命名建议：`{店铺名}_对账_{导出日期}_raw{ext}`（`导出日期` 为文件生成日或页面展示日，与团队约定一致即可；模板里可用 `downloadFileNameTemplate`）。

## 维护约定

- 拼多多数据中心「成交金额」等若长期抽不到可读数字：页面使用 **spider 字体**混淆，需解析接口 JSON 或按 `@font-face` 做 cmap 映射；脚本仅做同卡 `data-*`/文案兜底。
- 模板变更后，同步更新本文档。
- 若新增模块映射，需同步 `scripts/run_template_trial.py` 的 `--task-part` 规则。
